## 做了什么

- 中文描述 → 可检查、可修改的结构化条件 → 确定性筛选。阈值修改实时显示哪些股票进出名单，确认执行后才能保存对应结果。
- 60只当前沪深300研究样本，6个行业组，每组10只；另有中国平安、隆基绿能用于样本外对比。“样本外”指不在这60只筛选池内。
- 关键数字旁显示来源、时点、单位与口径；结果分为符合、不符合、数据待核验。缺失、过期、接口失败不会当成符合。
- 个股日线区间切换、茅台等已覆盖公告、关注股票对比、组合行业集中度与分散候选。
- 组合分析是近一年共同日期、每日按设定权重再平衡、不计费用的历史情境，和下面独立的买入持有回测口径不同。
- 模拟盘：使用标明日期的历史快照、模拟资金和碎股，不是实时交易；本浏览器保存，刷新保留，不计费用、分红和利息。
- 监控任务：服务器D1保存，公开访客使用签名HttpOnly会话隔离，可设计划、立即检查、暂停、查看最近检查及数据缺失。自动调度接口已加独立鉴权；公开版未完成安全调度绑定前，不能宣称关页面后会自动检查或通知。

## AI、程序、数据工具各负责什么

AI只解释用户意图、追问模糊的时间或阈值、保留多轮条件，输出白名单结构化条件。目标模型固定为 `gpt-5.4-mini`，使用OpenAI Responses API和严格JSON Schema；不把股票行情/持仓或数据接口密钥发给模型。程序校验字段、冲突和阈值，执行筛选、风险计算、来源核验；模型不能直接决定入选股票或编造事实数字。

运行时是否真的接通，以页面“AI连接”状态及 `AI_VALIDATION.md` 的真实调用记录为准。未配置Key时明确显示“尚未配置”，可选择免费的规则解析；模型异常不会悄悄回退并假装AI成功。已有模型接口与构造回复单元测试，不等于完成真实模型测评。

## 数据来源和边界

扶摇：指数成分、行业、上市日期、前复权日线、估值、累计利润表、交易日历、除权分红。iFinD：公告语义检索；历史回测另使用历史总股本。公告当前历史覆盖7/60，页面逐只列出覆盖状态；未覆盖、空响应、截断都不能解释为“没有公告”。

筛选主页面使用标明日期的历史快照，不是实时行情。监控复查调用实时接口，时点另列。利润同比用同币种累计归母利润、正基期；日波动是简单收益样本标准差。停牌/ST/上市日期不完整时显示未知，不能从K线起点臆测上市日期。今日分时、任意全A股搜索、全量公告覆盖未实现。公开仓库不提供受限缓存，须自行使用有权限的数据接口刷新。

## 启动和环境变量

Node.js 20.19+ / 22.12+（本次测试Node24）、Python3、curl。运行：

```sh
npm ci
# 在本地环境中设置FUYAO_API_KEY和IFIND_MCP_KEY，再取自己的授权数据。
python3 scripts/refresh_data.py
python3 scripts/refresh_ifind.py
# 服务器密钥写入未跟踪的.dev.vars；变量名参考.env.example。
npm run dev
```

开发脚本构建Worker、应用本地D1迁移并启动本地端口。`npm run build`产生 `dist/server/index.js`；托管部署使用 `.openai/hosting.json` 中的Site和D1绑定，生产秘密配置在Site运行时Secrets。公开仓库的托管配置不包含原Site项目ID，部署到自己的环境时自行配置目标Site或Wrangler D1。

| 变量 | 用途 | 必需情况 |
|---|---|---|
| FUYAO_API_KEY | 扶摇刷新与服务器监控复查 | 真实数据/复查 |
| IFIND_MCP_KEY | iFinD公告刷新与复查 | 公告功能 |
| OPENAI_API_KEY | gpt-5.4-mini服务端调用 | 选择AI理解时 |
| SESSION_SECRET | 签名匿名访客会话，30天，本机Cookie隔离任务 | 公开部署 |
| MONITOR_CRON_SECRET | 后台调度写接口独立鉴权 | 安全调度器接入时 |
| MARKET_DATA_CUTOFF | 可选日线刷新截止日，YYYY-MM-DD | 取数脚本，可选 |

不要把密钥放在浏览器、源码、README或公开仓库。`MARKET_DATA_CUTOFF`不能把当前估值或当前财报版本变成历史版本。生产固定快照与运行时秘密分开，清除浏览器会话会失去匿名任务访问；匿名身份不支持跨设备恢复。
